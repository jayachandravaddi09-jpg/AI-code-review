# Jayachandra Vaddi — Developer Portfolio

Personal developer portfolio website for **Jayachandra Vaddi** (`AI/ML Engineer | Python Full Stack Developer | Generative AI Enthusiast`), built with React, TypeScript, Tailwind CSS, Motion, and Express.

## Features

- **Hero & Portrait Showcase**: Circular glowing portrait frame, animated role typing effect, resume download CTA, and social links.
- **About & Verified Metrics**: Academic & internship overview paired with animated counters backed by verified project datasets (`70,000` patient records, `32,833` Spotify tracks, `73.35%` Random Forest accuracy).
- **Services & Interactive Skills**: Four core engineering service pillars and category-filtered skills across Languages, Frontend, Backend, Generative AI, Machine Learning, and Tools.
- **Experience, Education & Certificates**: Vertical timelines for the **Corizo Edutech** AI Internship (`June 2026 – September 2026`) and **Sri Krishnadevaraya University** (`M.Sc. Computer Science`, `2024 – 2026`), plus internship certificate details.
- **Project Showcase & Architecture Modal**: Detailed breakdown of *AI Code Review Assistant*, *Spotify Song Recommendation System*, and *Cardiovascular Disease Prediction*.
- **Resume Preview & Download**: Built-in PDF and formatted resume preview modal alongside `/api/resume/download` for one-click PDF downloads.
- **Contact Form**: Express backend (`POST /api/contact`) with validation and email copy utilities.

## Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Motion, Lucide React
- **Backend**: Node.js, Express
- **Build Tooling**: Vite 8, `tsx`

## Local Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

### Production Build

```bash
npm run build
npm start
```
